Project Setup Instructions

Prerequisite
- Ensure Node.js is installed on your system.

Step 1: Install Dependencies
Navigate to the root directory of the project and run:

    npm install

If you encounter any dependency conflicts, run the command with the force flag:

    npm install -f

Step 2: Run the Project
While in the root directory, start the development server using:

    npm run dev

Once the server is running, open the provided URL (usually http://localhost:8000) in any browser to view the application.
